Source only, not yet compiled or tested. Frozen terminal author delivery is preserved separately, with SHA256 manifest and complete Claude output. The initial Write versions also preserve the fixture alias defects the author fixed during its own review. No original repository or production files were changed.

1. Offline accounting now pays only measured/bounded execution gas. The prior unconditional L1 allowance is not evidence of actual L1 fees and has been removed from the calculation. The signed L1 ceiling is inert; there is no pending L1 debt or qualified L1 fee settlement in this version. Actual L1 fees remain the submitter's burden. Finite reserve availability does not guarantee chain inclusion.
2. Recovery requires its protected reserve to cover the payer-authorized per-transition cap. A fresh sponsor reservation must match the recovery's protected amount exactly. Existing pull credits remain separate and fully backed. A 1-wei test now uses an explicitly payer-signed 1-wei cap at initial enrollment rather than silently reducing a larger reserve through recovery.
3. Offline retries validate current stored operator/generation/authority revision/deadline plus reporter quorum or direct current caller before returning an idempotent acknowledgement. Stale authority or forged/absent approval cannot receive an accepted no-op. An unchanged valid request remains idempotent and pays once.
