# Firmwares that are KNOWN TO VERIFY the measured SEV hash table, by sha256 of the .fd file.
#
# WHY A PIN AND NOT A NAME. igvmbuilder emits the measured table for ANY firmware that declares a KERNEL_HASHES
# area, and a non-verifying firmware declares one too: the distro OvmfPkgX64 links BlobVerifierLibNull, which
# never looks at the table. So an IGVM can carry a byte-perfect measured table over a firmware that checks
# nothing, and every structural check - the directive, the split, the grant, the whole-table comparison - PASSES.
# Found by enclave-59 on 2026-09-24 by building exactly that IGVM; the structural inspector accepted it.
#
# Structure cannot tell a verifying firmware from a non-verifying one. Only the firmware's identity can, and what
# makes a firmware "verifying" is SUBSTITUTION EVIDENCE - a run in which it refused artifacts that did not match
# the table - never its filename, its .dsc, or the library it appears to link.
#
# The firmware is recoverable from a built IGVM: the pages at 0xffc00000 reassemble to the .fd file's sha256, so
# this pin is checkable after the fact and not only at build time.
#
# To add a line: run the substitution negative against that firmware, commit the evidence, and cite it here.
# Never add a firmware because it "should" verify.
