# Revised isolated Windows test launcher: build only

This source revision addresses independent review of r1. A watchdog thread is now established after assigning the launcher to its bounded Job Object and before creating PowerShell. It checks pressure and an entry-relative30-second deadline while child creation can be pending. This does not bound early setup before the watchdog itself exists or guarantee scheduling during arbitrary OS stalls. The original r1 timeout started only after child creation/resume; retain that limitation for the earlier artifact.

STARTUPINFOEX now supplies an explicit HANDLE_LIST containing exactly three duplicated stdin/stdout/stderr handles. The earlier bInheritHandles=true inherited all inheritable launcher handles; the Job Object itself was never inheritable. Memory observations now use a per-call stack structure, avoiding shared writable state between the watchdog and main thread.
