Don't take this page's word for it: run the check now

Your browser loads Cloud Provider's open-source verifier (@Cloud Providersh/verifier) and checks one live enclave over your own connection: its hardware report up to the silicon vendor's root, its release's Sigstore provenance against the public EnclaveHost/enclave repo, and whether the two measurements match. Your dashboard runs the same check on each deployment's enclave.

    The verifier is served from this site (same-origin, version-pinned); the Sigstore bundles and AMD certificate collateral it checks arrive through Cloud Provider's CORS proxies. For a fully independent check, run Cloud Provider attestation verify -e <enclave-host> -r EnclaveHost/enclave with Cloud Provider-cli against any enclave.
